# HR Analytics Power BI Dashboard

## Project Overview
This project is an HR Analytics Dashboard created using Microsoft Power BI.

The dashboard helps analyze employee data, attrition, salary, age, department, job roles, and other HR-related insights.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Dashboard Pages
### Page 1 – HR Overview
- Total Employees
- Average Monthly Income
- Average Age
- Attrition Rate
- Employee Analysis
- HR-related visualizations

### Page 2 – Attrition Analysis
- Attrition analysis
- Age-wise analysis
- Employee-related insights
- Interactive charts and filters

## Key Metrics
- Total Employees: 1.47K
- Average Monthly Income: 6.50K
- Average Age: 36.92
- Attrition Rate: 16.12%

## Project Objective
The objective of this project is to understand employee data and identify important HR trends and attrition-related insights using Power BI.

## Conclusion
This dashboard provides an interactive way to analyze employee data and supports better understanding of HR and attrition trends  ## Dashboard Preview
